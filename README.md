<details>
<summary>Como são calculadas as métricas?</summary>

- **Repositórios trabalhados:** repositórios distintos com commits, issues, pull requests ou revisões de pull requests registrados pelo GitHub.
- **Commits e interações:** contribuições atribuídas à minha conta pelo GitHub desde sua criação. Interações são a soma de issues, pull requests e revisões.
- Os totais incluem repositórios privados acessíveis ao token configurado, sem divulgar seus nomes. Contribuições não reconhecidas pelo GitHub ou inacessíveis ao token não entram na contagem.

</details>

<details>
<summary>Configurar atualização automática</summary>

1. Crie um [personal access token clássico](https://github.com/settings/tokens/new) da conta `Joaofonsecaf` com os escopos `repo` e `read:user`. Para organizações, autorize o token via SSO quando necessário; `read:org` pode ser necessário para acesso a dados da organização.
2. Adicione o token como secret `PROFILE_STATS_TOKEN` em **Settings → Secrets and variables → Actions** deste repositório. Nunca cole o token no README.
3. Em **Settings → Actions → General**, permita que o `GITHUB_TOKEN` tenha permissão de escrita no repositório, se necessário.
4. Em **Actions → Atualizar métricas do perfil**, execute **Run workflow**. Depois, a atualização acontece diariamente.

Somente os totais são publicados aqui; mantenha o token com acesso apenas aos dados que deseja incluir. Se o token expirar ou perder acesso, atualize o secret e execute o workflow novamente.

</details>
